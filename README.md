# My Snowball

A debt payoff planner: enter balances and rates, compare repayment strategies, and get your debt-free date — without your financial data ever leaving your device.

**Live:** [mysnowballapp.com](https://mysnowballapp.com)

## Highlights
- 100% on-device: debts, payments, and projections stay in the browser
- Offline-first PWA with local backup and restore
- Strict Content Security Policy; all strategy simulation runs client-side
- One-time Pro (unlimited debts, PDF export) via Stripe + RevenueCat Web Billing
